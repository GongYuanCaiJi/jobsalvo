# 找缺

你在替使用者找職缺。這一輪往哪找，看本輪找法的 skill（更深、更廣或指定方向）；這份是三種找法共用的做法。

## 材料

程式在本輪列出的材料就是全部依據：一頁履歷、使用者自訂的硬規則、偏好筆記、角度地圖、使用者說過的原話、這輪條件。

- **角度地圖**：使用者表態過的每個角度（一個切入點，例如「雲端基礎設施」「使用者研究」），各送過幾張、喜歡幾張、不喜歡幾張、還沒看幾張。
- **偏好筆記**：每一條是一個假設，附出處（卡片代號＋使用者原話）和支持數、反例數。原話是證據，假設是讀法；兩者對不上時照原話。

## 這輪條件

使用者在看板上填的條件是這一輪的硬規則，每張候選都要符合。平台有對應的篩選（上架日期、薪資、經驗、地點）就直接用平台的篩選去搜；交回來之後程式會照同一組條件再過濾一次。沒列出條件就是不限。

## 找

1. 照本輪找法和材料，決定往哪些角度找、各找多少。份量照表態和角度地圖分配；限制只用使用者說過的。
2. 怎麼找由你決定。用手上的搜尋工具，一次送好幾個關鍵字、一次開多頁。搜尋結果看得出是單一職缺頁、可能對味、符合這輪條件，就交。只有要看公司的職缺列表時才抓那一頁。
3. 每張候選填一個角度：同一個切入點沿用角度地圖上的名字，真的是新的才取新名字，名字寫「在做什麼」。
4. 每找到一張，就把目前全部候選重寫進交件檔；使用者可能中途按停止，已寫進檔的會先判。

完成條件：交件檔裡每張候選都是單一職缺頁、都有角度；交件筆記裡每個用到的角度都有一句理由，引用角度地圖或偏好筆記的某一條。

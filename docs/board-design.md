# 看板設計規格

看板(`board/board.css`、`board/board.js`)的字級、字重、行高、間距、圓角、陰影、顏色只准用這份列的 token。這份只寫每個 token 的用途和規則;值只定在 `board/board.css` 的 `:root`,要知道值去那裡看。深色主題在 `:root[data-theme="dark"]` 那段改同名 token 的值,不另取名字;`data-theme` 由 board.js 依外觀切換(淺色／深色／跟系統,記在 localStorage `jobsalvo.theme`)設在 `<html>` 上,跟系統時照 `prefers-color-scheme`。

- 擋寫死的值:`.stylelintrc.json`(Stylelint + `stylelint-declaration-strict-value`,經 `.pre-commit-config.yaml` 跑)。`calc()`、`color-mix()` 這類函式和 `var(--x, 後備值)` 一律不准;放行的只有 `0`、`auto`、`inherit`、`initial`、`unset`、`none`、`normal`、`transparent`、`currentColor`。
- 擋名字對不上:`tests/test_board_tokens.py`(這份列的 token 名字跟 `:root` 定義的一模一樣,用到的 `var(--x)` 都有定義)。
- 擋對比不夠:`tools/board_check.py` 的無障礙檢查(axe,WCAG 2.2 AA)在淺深兩主題量。
- 依據:研究筆記 [docs/research/2026-10-30-board-design-system.md](research/2026-10-30-board-design-system.md) 的「對看板的決定」,下面寫「決定 N」。

## 字級

依據:決定 3(local policy,Pajamas 字級):密集卡片內文、次要標記、醒目三階,另留一階給輔助資訊(公司列附註、卡片地點與日期、附件)。

| token | 用在 |
|---|---|
| `--text-xs` | 標籤、徽章、次要說明、表頭 |
| `--text-sm` | 輔助資訊、小按鈕、分頁、篩選鈕 |
| `--text-md` | 內文(`body`)、輸入框、一般按鈕 |
| `--text-lg` | 卡片標題、分類標題、區塊標題;手機輸入框(iOS 低於 16px 會整頁放大) |
| `--text-xl` | 頁面標題、要唸的稿子、設定分組 |
| `--text-2xl` | 頁首大標、結果數 |

大字讀稿的字級由使用者自己調,放在 `--rd-fs`(board.js 改這個值)。

## 字重

依據:決定 3 延伸(local policy)。`--weight-normal`、`--weight-medium`、`--weight-semibold`、`--weight-bold` 四階。系統中文字型(蘋方)最粗只到 semibold,再粗畫出來一樣;英數字才分得出 bold。

## 行高

依據:local policy(Primer 行高無單位)。讀稿模式要拉開行距,另留一階。

| token | 用在 |
|---|---|
| `--leading-tight` | 大標、單行圖示鈕 |
| `--leading-snug` | 卡片標題、題目、清單一行 |
| `--leading-normal` | 內文(`body`) |
| `--leading-relaxed` | 說明段落、等寬小字 |
| `--leading-loose` | 要唸的稿子、大字讀稿 |

## 間距(margin / padding / gap)

依據:決定 2(local policy,Pajamas 間距):以 `--space-8` 為基準。`--space-1` 只當同一個框裡格子之間的細縫(gap,透出 `--line-soft` 的底)。`--space-2`、`--space-4`、`--space-6` 只用在元件內(圖示與字、膠囊的內距);`--space-12` 只當內距(按鈕、輸入框、分頁、列的左右內距,和容器四邊內距),外距與 gap 不用它;`--space-16`、`--space-24`、`--space-32`、`--space-48`、`--space-64` 用在外距與 gap。

| 負值 token | 用在 |
|---|---|
| `--space-n1` | 手機底部導覽目前那組的上緣粗線蓋住導覽列自己那條 `--line` |
| `--space-n4` | 輕量按鈕列往左貼齊、分頁箭頭兩側、待補答案底色外擴 |
| `--space-n16` | 手機橫捲列貼齊螢幕兩側(抵掉頁面左右內距)、讀卡模式底部表態列貼齊卡片 |
| `--space-n64` | 手機橫捲列兩端的箭頭疊在頭尾那顆上 |

負值只准拿來抵掉同一個元件裡對應的正值,不拿來排版。

## 圓角

依據:Primer 圓角(small、medium、large、full)。巢狀容器裡面那層用外層同一階。

| token | 用在 |
|---|---|
| `--radius-sm` | 小標籤、徽章、圖片 |
| `--radius-md` | 按鈕、輸入框、篩選鈕、選單項目、小面板 |
| `--radius-lg` | 卡片、公司清單、面板、選單、對話框 |
| `--radius-full` | 膠囊、圓點、圓形鈕 |

## 陰影

依據:Primer 陰影分「靜止」與「浮起」(resting / floating);local policy 補黏住的列與標示線。淺色主題的陰影要淡。

| token | 用在 |
|---|---|
| `--shadow-sm` | 卡片、回頂鈕、黏在底下的設定存檔列 |
| `--shadow-lg` | 選單、訊息條、存檔條、履歷頁、關閉鈕 |
| `--shadow-sticky-top` | 捲下去後黏在上面的分頁列 |
| `--shadow-sticky-bottom` | 讀卡模式黏在底下的表態列 |
| `--shadow-ring` | 跳過來那張閃一下 |
| `--shadow-mark` | 打開的公司列、目前那一列、選中的切角(左邊一條主色線) |
| `--shadow-mark-warn` | 要你處理的那幾列(左邊一條警示線) |

## 顏色

依據:決定 1(主流,Primer / Pajamas):按用途命名,淺深主題同名、各自的值;決定 6(WCAG 2.2 AA):字 4.5:1、大字與非文字元件 3:1,兩個主題都要過。

| token | 用途 |
|---|---|
| `--bg` | 頁面底 |
| `--surface` | 卡片、面板、輸入框底 |
| `--surface-2` | 次一層底(打開的列、膠囊、選單) |
| `--side` | 側欄、頁首列、手機底部導覽的底(比 `--bg` 淺一點);標誌履歷上的照片和字 |
| `--ink` | 主要文字 |
| `--ink-2` | 內文段落、清單裡的職稱(比 `--ink` 淡一階) |
| `--ink-dim` | 次要文字、圖示 |
| `--ink-mute` | 最淡的字(計數、欄名、沒資料) |
| `--line` | 分隔線、卡片外框(裝飾,不靠它認出元件) |
| `--line-soft` | 同一個框裡格子之間的細縫(側欄分頁、要你處理、流程三格、表格列) |
| `--line-ctrl` | 次要按鈕、篩選鈕的外框(按鈕靠字認出,框只是收邊) |
| `--line-strong` | 輸入框、分段切換的外框(靠它認出元件) |
| `--accent` | 主要按鈕底、選中的框 |
| `--accent-soft` | 選中的淡底 |
| `--accent-ink` | 主色的字、焦點框 |
| `--accent-text` | 主要按鈕上的字 |
| `--accent-text-dim` | 主要按鈕上的次要字(張數)、訊息條的第二行 |
| `--warn` | 要你動手、出問題 |
| `--warn-soft` | 警示淡底 |
| `--warn-dot` | 「要你處理」標題前的小方塊(非文字) |
| `--fit` | 對得上你、新進、表態「喜歡」的字 |
| `--fit-soft` | 新進徽章、「近 7 天」的淡底 |
| `--mood-dislike` | 表態「不喜歡」的字 |
| `--mood-grow` | 表態「差一點」的字 |
| `--brand` | 只用在標誌(朱砂紅);不拿來講狀態、不當按鈕或一般文字的顏色 |
| `--paper` | 履歷、截圖、PDF 的白紙(兩個主題都白) |
| `--paper-ink` | 白紙上的字 |
| `--overlay` | 彈窗後面的半透明黑底 |

主色是墨色:淺色主題黑底白字、深色主題淺底深字,選中的分頁和主要按鈕都用它;彩色只拿來講狀態(警示、對得上、四種表態)。主色當字、焦點框一律用 `--accent-ink`(`--accent` 當字在深色主題對比不夠);`--paper`、`--paper-ink`、`--overlay` 兩個主題同值。

## 元件

每種一句:用在哪、長怎樣、用哪些 token。依據:決定 4(主流,Primer / Pajamas 元件目錄):同一種互動只有一種長相。

- **主要按鈕**(`.stage-b.adv`、`.stage-b.add`、`.cfg-b.go`、`.iv-read`、存檔鈕):一列只有一顆的下一步;實心 `--accent` 底、`--accent-text` 字、`--radius-md`、左右 `--space-12` 以上。可以投了那一頁有常用答案待確認時,「一條一條確認答案」(`.ansq-go`)是整頁唯一的實心,「讓 Agent 填表單」「送出已確認的」退成次要按鈕;卡上的「讓 Agent 填這張」在還有答案待確認時也退成次要,下面一行 `.ap-hint`(`--text-sm` `--ink-dim`)講先確認答案;設定頁的儲存鈕只在有改動時實心。準備履歷那一頁只有「準備這 N 張」實心,「以後新進的也自動準備」是同一列的開關。
- **次要按鈕**(`.stage-b`、`.cfg-b`、`.oc-b`、`.ctl-act`、`.iv-ghost`):結果那一排(`.oc-row`)間隔 `--space-4`、一顆左右 `--space-8`,六顆在卡上一行排得下;同一列的其他動作;`--line` 框、透明或 `--surface` 底、`--ink` / `--ink-dim` 字、同高同圓角 `--radius-md`。
- **輕量按鈕**(`.stage-b.back`、`.cust-b.ask`、`.upd-chip`、`.iv-rm`、`.more-b` ⋯):退回、要客製、罕用動作;沒框的 `--ink-dim` 字,滑過才有底色或底線。
- **開關**(`.sw-b`、`.sw`、`.sw-st`):打開一條長期自動流程(準備履歷「以後新進的也自動準備」);沒框的文字鈕(高 40,滑過 `--surface-2`),前面一條 30×18 的軌道加圓鈕(關 `--line-strong`、開 `--accent`,圓鈕 `--surface`),後面 `--ink-mute` 寫目前狀態(關／開),`role="switch"` 加 `aria-checked`。
- **膠囊鈕**(`.rchip`、`.pv-b`、`.afree-b`、`.ff`):可切換的小條件;`--radius-full`、`--text-xs`,開著時 `--accent-soft` 底 `--accent-ink` 字。
- **分段切換**(`.fb-btns` 表態、`.vd-seg` 履歷與語言):幾個互斥選項連成一條;外框 `--line-strong`、格線 `--line`、`--surface` 底,選中 `--accent-soft` 底。表態四顆由壞到好排:不喜歡、普通、差一點、喜歡,字各自一色(`--mood-dislike`、`--ink-dim`、`--mood-grow`、`--fit`)半粗,選中時保留那個顏色;讀卡模式桌機的鍵盤 1–4 跟這個順序一樣。
- **標籤與徽章**(`.tag`、`.pill`、`.barchip`、`.risk`、`.sent-badge`、`.app-badge`、`.iv-for`、`.iv-st`、`.ev-weak`):卡上的分類與狀態;`--text-xs`、`--surface-2` 底、不加框、`--radius-sm`、`--ink-dim` 字,要你動手的用 `--warn-soft` 底 `--warn` 字。
- **卡片**(`.card`):一個職缺;`--surface` 底、`--line` 框、`--radius-lg`、`--shadow-sm`、內距 `--space-16`,標題 `--text-lg`,事實列 `--text-sm`。
- **公司列**(`.cogrid`、`.cohead`、`.cocards`):公司清單一列一家,點開是那家的卡;整份只有上下兩條 `--line`、列與列之間一條 `--line`,不包外框,列高 46、`--text-md` 名字、`--text-sm` `--ink-mute` 計數;名字下面一行 `--text-sm` `--ink-dim` 是這家前兩個職稱(收起來也知道裡面是什麼,打開時收掉;已移除那一頁這一行上面另起一行「原本在」加短名),打開的那列 `--surface-2` 底加 `--shadow-mark`;整家看完的那列名字退成 `--ink-dim`(不用 opacity:半透明會把 `--ink-mute` 的計數壓到 4.5 以下)。狀態張數(`.codot`)在「全部」「已移除」頁和手機上後面寫字(`.codot-w`,跟分頁同名,例「待你決定 19」「出錯了 5」),不只靠圖示。已移除那一頁的時間寫最近那張「N 天前移除」(整批移除記了日期;單張移除沒記日期的照舊寫進板時間),公司照移除時間排、最近的在上面。手機一列分兩行:第一行公司名(長的最多折兩行)、狀態張數、「共 N」;第二行(`.cometa`,`--text-sm`)新進張數、進板時間,接著職稱。找工作那幾頁(`.cotable`)整份包成一塊 `--surface` 底、`--line` 框的表:桌機上面一條表頭(`.cothd`,`--side` 底、`--text-xs` `--ink-mute`:公司／職缺／近 7 天／進板／共),一列一家照欄位對齊,近 7 天新進的張數是 `--fit-soft` 底 `--fit` 字的小徽章,進板時間和「共」用 `--mono`。一列是 `.corow` 包著 `details.cogrp` 和那一家的 ⋯:⋯ 疊在列右上角、不放進 `summary` 裡(summary 裡不准有可聚焦的東西,axe 的 nested-interactive),收起來時照樣看得到、按得到。
- **標誌**(`.logo`、`.logo-r`、`.logo-c`、`.logo-mark`):文字標誌是「jobsalvo」,job 是 `currentColor`、salvo 是 `--brand`。job、sa 就是正文的字;l 畫成斜架在 v 上的砲管,最後的 o 畫成砲車輪子(十字輻條),砲口正前方沿砲管方向噴出一條淡煙(五顆越來越小的煙點,三成不透明),上方射出三張排成扇形的履歷(履歷上的照片和字 `--side`)。放在桌機側欄最上面(`--text-2xl` 粗)和手機頁頂(`--text-lg` 粗)。側欄收成窄欄時換成小圖示(`.logo-mark`,32×32):就是射出去的那一份,一條煙加三張履歷;瀏覽器分頁小圖示是同一張,系統深色時換深色那一份。大尺寸(字 40px 以上,例如 README、影片、分享預覽圖)輪子改八根輻條,其餘一樣。使用規則:四周至少留一個字母 o 的寬度不放別的東西;文字標誌不小於 16px 字、小圖示不小於 16px;只用 `--brand` 這一個顏色(淺色 #B8322A、深色 #D9584A;單色場合整個用 `currentColor`);不拉長壓扁、不旋轉、不加陰影或外框、不換別的顏色、不拆開重排。
- **導覽列**(`#tabs`、`.tabgrp-k`、`.tabbox`、`.tab`、`.botnav`、`.bn-b`):分「找工作／投遞流程／出錯與設定」三組。桌機是左邊固定的一條側欄(`--side` 底、右邊一條 `--line`、寬 232):最上面是標誌(`.side-brand`),每組一個框(組名 `--text-xs` 半粗 `--ink-mute` 寫在框上面;框 `--line` 框、`--radius-lg`,列與列之間一條 `--line-soft` 細縫),一列一頁高 36、名字 `--text-sm`、張數 `--mono` `--text-xs` 靠右,目前那頁 `--accent` 底 `--accent-text` 半粗字、張數 `--accent-text-dim`(`aria-current="page"`);可以投了有答案待確認時張數前面寫「42 答案」(`--warn` 粗字),出錯了有卡時張數 `--warn` 粗字;設定(齒輪加字)在側欄最底下、上緣一條 `--line`。標誌那一列最右邊一顆收合鈕(`.side-tog`,側欄圖示、線寬 1.5、`--ink-dim`,`aria-label` 收起側欄／展開側欄加 `aria-expanded`):收起後側欄縮成寬 64 的窄欄(最上面是標誌小圖示,下面只剩每頁的圖示和張數,答案待確認、出錯了的警示字照樣在,每一頁照樣點得到),主區吃滿,頁頂麵包屑左邊出現同一顆鈕可以展開;狀態記在 localStorage `jobsalvo.side`,讀不到就是展開。手機頂端只放目前那一組的一排格子(找工作六格、投遞流程五格、出錯與設定三格,框同上),每格平分寬度、名字 `--text-md` 在上、張數在下、高 52,不橫捲、不黏著(第一屏留給這一頁);投遞流程那排可以投了那一格寬 1.5 份;380px 以下投遞流程那排寫短名(`data-short`)。換組用底部固定的三組導覽(`.botnav`,高 60、`--side` 底、上緣 `--line`):圖示加組名 `--text-xs`,目前那組 `--ink` 半粗、上緣一條 2px `--ink`,其他 `--ink-dim`;徽章(`.bn-n`,`--mono` `--warn` 粗字)投遞流程寫常用答案待確認的條數、出錯與設定寫出錯了的張數;按一組回到那一組上次停的分頁(記在 localStorage `jobsalvo.lasttab`)。讀卡模式收起來。

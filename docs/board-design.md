# 看板設計規格

看板(`board/board.css`、`board/board.js`)的字級、字重、行高、間距、圓角、陰影、顏色只准用這份列的 token。這份只寫每個 token 的用途和規則;值只定在 `board/board.css` 的 `:root`,要知道值去那裡看。深色主題在 `:root[data-theme="dark"]` 那段改同名 token 的值,不另取名字;`data-theme` 由 board.js 依外觀切換(淺色／深色／跟系統,記在 localStorage `jobsalvo.theme`)設在 `<html>` 上,跟系統時照 `prefers-color-scheme`。

- 擋寫死的值:`.stylelintrc.json`(Stylelint + `stylelint-declaration-strict-value`,經 `.pre-commit-config.yaml` 跑)。`calc()`、`color-mix()` 這類函式和 `var(--x, 後備值)` 一律不准;放行的只有 `0`、`auto`、`inherit`、`initial`、`unset`、`none`、`normal`、`transparent`、`currentColor`。
- 擋名字對不上:`tests/test_board_tokens.py`(這份列的 token 名字跟 `:root` 定義的一模一樣,用到的 `var(--x)` 都有定義)。
- 擋對比不夠:`tools/board_check.py` 的無障礙檢查(axe,WCAG 2.2 AA)在淺深兩主題量。
- 依據:研究筆記 [docs/research/2026-10-30-board-design-system.md](research/2026-10-30-board-design-system.md) 的「對看板的決定」,下面寫「決定 N」。

## 字級

依據:決定 3(local policy,Pajamas 字級):密集卡片內文、次要標記、醒目三階,另留一階給輔助資訊(公司列附註、卡片地點與日期、附件)。

| token | 用在 |
|---|---|
| `--text-xs` | 標籤、徽章、次要說明、表頭 |
| `--text-sm` | 輔助資訊、小按鈕、分頁、篩選鈕 |
| `--text-md` | 內文(`body`)、輸入框、一般按鈕 |
| `--text-lg` | 卡片標題、分類標題、區塊標題;手機輸入框(iOS 低於 16px 會整頁放大) |
| `--text-xl` | 頁面標題、要唸的稿子、設定分組 |
| `--text-2xl` | 頁首大標、結果數 |

大字讀稿的字級由使用者自己調,放在 `--rd-fs`(board.js 改這個值)。

## 字重

依據:決定 3 延伸(local policy)。`--weight-normal`、`--weight-medium`、`--weight-semibold`、`--weight-bold` 四階。系統中文字型(蘋方)最粗只到 semibold,再粗畫出來一樣;英數字才分得出 bold。

## 行高

依據:local policy(Primer 行高無單位)。讀稿模式要拉開行距,另留一階。

| token | 用在 |
|---|---|
| `--leading-tight` | 大標、單行圖示鈕 |
| `--leading-snug` | 卡片標題、題目、清單一行 |
| `--leading-normal` | 內文(`body`) |
| `--leading-relaxed` | 說明段落、等寬小字 |
| `--leading-loose` | 要唸的稿子、大字讀稿 |

## 間距(margin / padding / gap)

依據:決定 2(local policy,Pajamas 間距):以 `--space-8` 為基準。`--space-2`、`--space-4`、`--space-6` 只用在元件內(圖示與字、膠囊的內距);`--space-12` 只當內距(按鈕、輸入框、分頁、列的左右內距,和容器四邊內距),外距與 gap 不用它;`--space-16`、`--space-24`、`--space-32`、`--space-48`、`--space-64` 用在外距與 gap。

| 負值 token | 用在 |
|---|---|
| `--space-n4` | 輕量按鈕列往左貼齊、分頁箭頭兩側、待補答案底色外擴 |
| `--space-n16` | 手機橫捲列貼齊螢幕兩側(抵掉頁面左右內距)、讀卡模式底部表態列貼齊卡片 |
| `--space-n64` | 手機橫捲列兩端的箭頭疊在頭尾那顆上 |

負值只准拿來抵掉同一個元件裡對應的正值,不拿來排版。

## 圓角

依據:Primer 圓角(small、medium、large、full)。巢狀容器裡面那層用外層同一階。

| token | 用在 |
|---|---|
| `--radius-sm` | 小標籤、徽章、圖片 |
| `--radius-md` | 按鈕、輸入框、篩選鈕、選單項目、小面板 |
| `--radius-lg` | 卡片、公司清單、面板、選單、對話框 |
| `--radius-full` | 膠囊、圓點、圓形鈕 |

## 陰影

依據:Primer 陰影分「靜止」與「浮起」(resting / floating);local policy 補黏住的列與標示線。淺色主題的陰影要淡。

| token | 用在 |
|---|---|
| `--shadow-sm` | 卡片、回頂鈕、黏在底下的設定存檔列 |
| `--shadow-lg` | 選單、訊息條、存檔條、履歷頁、關閉鈕 |
| `--shadow-sticky-top` | 捲下去後黏在上面的分頁列 |
| `--shadow-sticky-bottom` | 讀卡模式黏在底下的表態列 |
| `--shadow-ring` | 跳過來那張閃一下 |
| `--shadow-mark` | 打開的公司列、目前那一列、選中的切角(左邊一條主色線) |
| `--shadow-mark-warn` | 要你處理的那幾列(左邊一條警示線) |

## 顏色

依據:決定 1(主流,Primer / Pajamas):按用途命名,淺深主題同名、各自的值;決定 6(WCAG 2.2 AA):字 4.5:1、大字與非文字元件 3:1,兩個主題都要過。

| token | 用途 |
|---|---|
| `--bg` | 頁面底 |
| `--surface` | 卡片、面板、輸入框底 |
| `--surface-2` | 次一層底(打開的列、膠囊、選單) |
| `--ink` | 主要文字 |
| `--ink-dim` | 次要文字、圖示 |
| `--ink-mute` | 最淡的字(計數、欄名、沒資料) |
| `--line` | 分隔線、卡片外框(裝飾,不靠它認出元件) |
| `--line-strong` | 輸入框、分段切換的外框(靠它認出元件) |
| `--accent` | 主要按鈕底、選中的框 |
| `--accent-soft` | 選中的淡底 |
| `--accent-ink` | 主色的字、焦點框 |
| `--accent-text` | 主要按鈕上的字 |
| `--warn` | 要你動手、出問題 |
| `--warn-soft` | 警示淡底 |
| `--paper` | 履歷、截圖、PDF 的白紙(兩個主題都白) |
| `--paper-ink` | 白紙上的字 |
| `--overlay` | 彈窗後面的半透明黑底 |

主色當字、焦點框一律用 `--accent-ink`(`--accent` 當字在深色主題對比不夠);`--paper`、`--paper-ink`、`--overlay` 兩個主題同值。

## 其他 token

| token | 用在 |
|---|---|
| `--font` | 全頁(系統字) |
| `--mono` | 碼錶、鍵盤提示、prompt 內容(系統等寬字) |
| `--chev` | 手機橫捲列兩端的圓形箭頭圖(淺深各一份,圖裡的顏色跟 `--surface`、`--line`、`--ink` 一樣) |
| `--dock-h` | 訊息條往上讓開存檔條(board.js 改成存檔條的高度) |
| `--rd-fs` | 大字讀稿(board.js 改成使用者選的字級) |

## 元件

每種一句:用在哪、長怎樣、用哪些 token。依據:決定 4(主流,Primer / Pajamas 元件目錄):同一種互動只有一種長相。

- **主要按鈕**(`.stage-b.adv`、`.stage-b.add`、`.cfg-b.go`、`.iv-read`、存檔鈕):一列只有一顆的下一步;實心 `--accent` 底、`--accent-text` 字、`--radius-md`、左右 `--space-12` 以上。可以投了那一頁有常用答案待確認時,「一條一條確認答案」(`.ansq-go`)是整頁唯一的實心,「讓 Agent 填表單」「送出已確認的」退成次要按鈕;卡上的「讓 Agent 填這張」在還有答案待確認時也退成次要,下面一行 `.ap-hint`(`--text-sm` `--ink-dim`)講先確認答案;設定頁的儲存鈕只在有改動時實心。準備履歷那一頁只有「準備這 N 張」實心,「以後新進的也自動準備」是同一列的開關。
- **次要按鈕**(`.stage-b`、`.cfg-b`、`.oc-b`、`.ctl-act`、`.iv-ghost`):結果那一排(`.oc-row`)間隔 `--space-4`、一顆左右 `--space-8`,六顆在卡上一行排得下;同一列的其他動作;`--line` 框、透明或 `--surface` 底、`--ink` / `--ink-dim` 字、同高同圓角 `--radius-md`。
- **輕量按鈕**(`.stage-b.back`、`.cust-b.ask`、`.upd-chip`、`.iv-rm`、`.more-b` ⋯):退回、要客製、罕用動作;沒框的 `--ink-dim` 字,滑過才有底色或底線。
- **開關**(`.sw-b`、`.sw`、`.sw-st`):打開一條長期自動流程(準備履歷「以後新進的也自動準備」);沒框的文字鈕(高 40,滑過 `--surface-2`),前面一條 30×18 的軌道加圓鈕(關 `--line-strong`、開 `--accent`,圓鈕 `--surface`),後面 `--ink-mute` 寫目前狀態(關／開),`role="switch"` 加 `aria-checked`。
- **膠囊鈕**(`.rchip`、`.pv-b`、`.afree-b`、`.ff`):可切換的小條件;`--radius-full`、`--text-xs`,開著時 `--accent-soft` 底 `--accent-ink` 字。
- **分段切換**(`.fb-btns` 表態、`.vd-seg` 履歷與語言、`.iv-kind`):幾個互斥選項連成一條;外框 `--line-strong`、格線 `--line`,選中 `--accent-soft` 底 `--accent-ink` 字。
- **標籤與徽章**(`.tag`、`.pill`、`.barchip`、`.risk`、`.sent-badge`、`.app-badge`、`.iv-for`、`.iv-st`、`.ev-weak`):卡上的分類與狀態;`--text-xs`、`--surface-2` 底、不加框、`--radius-sm`、`--ink-dim` 字,要你動手的用 `--warn-soft` 底 `--warn` 字。
- **卡片**(`.card`):一個職缺;`--surface` 底、`--line` 框、`--radius-lg`、`--shadow-sm`、內距 `--space-16`,標題 `--text-lg`,事實列 `--text-sm`。
- **公司列**(`.cogrid`、`.cohead`、`.cocards`):公司清單一列一家,點開是那家的卡;整份只有上下兩條 `--line`、列與列之間一條 `--line`,不包外框,列高 46、`--text-md` 名字、`--text-sm` `--ink-mute` 計數;名字下面一行 `--text-sm` `--ink-dim` 是這家前兩個職稱(收起來也知道裡面是什麼,打開時收掉;已移除那一頁這一行上面另起一行「原本在」加短名),打開的那列 `--surface-2` 底加 `--shadow-mark`;整家看完的那列名字退成 `--ink-dim`(不用 opacity:半透明會把 `--ink-mute` 的計數壓到 4.5 以下)。狀態張數(`.codot`)在「全部」「已移除」頁和手機上後面寫字(`.codot-w`,跟分頁同名,例「待你決定 19」「出錯了 5」),不只靠圖示。已移除那一頁的時間寫最近那張「N 天前移除」(整批移除記了日期;單張移除沒記日期的照舊寫進板時間),公司照移除時間排、最近的在上面。手機一列分兩行:第一行公司名(長的最多折兩行)、狀態張數、「共 N」;第二行(`.cometa`,`--text-sm`)新進張數、進板時間,接著職稱。一列是 `.corow` 包著 `details.cogrp` 和那一家的 ⋯:⋯ 疊在列右上角、不放進 `summary` 裡(summary 裡不准有可聚焦的東西,axe 的 nested-interactive),收起來時照樣看得到、按得到。
- **導覽列**(`#tabs`、`.tabgrp-k`、`#tabs .tab`):頁頂一條,分「找工作／投遞流程／管理」三組,組名 `--text-xs` `--ink-mute` 寫在每組前面;分頁是沒框的文字鈕,`--text-sm` `--ink-dim` 字、張數 `--ink-mute`,滑過 `--surface-2`,目前那一頁 `--accent-soft` 底 `--accent-ink` 半粗字(`aria-current="page"`),不放圖示;下緣一條 `--line`,黏在頂端。桌機頁頂排兩列(找工作一列、其他兩組一列,管理靠右),捲下去縮成一列、寫全名加張數,拿掉分頁之間的箭頭;寬度真的不夠才退回短名(`data-short`,CSS `content` 畫)。投遞流程裡分頁之間是 › 箭頭,面試準備前面換成一個 · (已投出到面試準備不是同一條流水線的下一站)。手機是兩列格子、不橫捲:找工作一列、投遞流程一列,每列平分寬度,一格一頁,名字 `--text-sm` 在上、張數 `--text-xs` 在下,格高 44;可以投了有 ⚠ 答案時張數跟名字同一行、「⚠42 答案」自己一行(並排時 34 跟 42 看起來像兩個張數);投遞流程那列可以投了那一格寬 1.5 份;組名不寫在列上(每組是 `role="group"` 加組名);右邊一欄上格「設定」(齒輪加字)、下格「全部分頁」,欄左一條 `--line`;出錯了、已移除只收在「全部分頁」,有出錯的卡時「全部分頁」那一格的圖示換成「出錯了 N」(`.ta-te`,`--ink` 字),外面看得到。380px 以下投遞流程那列改寫短名、右欄不放圖示(「全部分頁」折兩行)。捲下去只留目前那頁所在的一列(在管理那組時留投遞流程)和「全部分頁」,按一下分頁就換頁。
- **全部分頁**(`#taball`、`.taball-m`):只在手機出現,導覽列右邊那欄的下格(圖示加一行 `--text-xs`「全部分頁」);打開是蓋在導覽列下方的清單(`--surface` 底、`--shadow-lg`、最高 75vh 可捲),照導覽列一樣三組,一項高 44、名字加張數,警示張數(可以投了的答案待確認)在名字後面 `--warn` 小字,目前那頁 `--accent-soft`;選了就換頁並關閉,按外面或 Esc 也關;視窗放大到桌機版面時也關。看板一打開一定是關的。清單最下面是外觀切換。
- **頁首**(`#pagehd`、`.pg-t`、`.pg-d`):每個分頁正文最上面一行,分頁名 `--text-xl` 粗字加一句這頁要做什麼 `--text-sm` `--ink-dim`,同一條基線;手機縮成 `--text-md` / `--text-xs` 一行。讀卡模式收起來。
- **外觀切換**(`.theme-seg`、`[data-themeset]`):淺色／深色／跟系統三格的分段切換(同分段切換的長相),預設跟系統。桌機頁頂工具列只放一顆圖示鈕(`.theme-w` 裡的 `[data-themeopen]`,同頁首工具鈕),點了下面彈一張小卡(`.theme-pop`,`--surface` 底、`--line` 框、`--radius-lg`、`--shadow-lg`)放三格,按外面或 Esc 收;手機在「全部分頁」清單最下面。
- **篩選鈕**(`.ctl` + `.ctlmenu`):「鍵 值 ▾」打開一張選單;沒框的文字鈕,滑過 `--surface-2`,選單 `--radius-lg` `--shadow-lg`,選中那項 `--accent-soft`。手機整排收成一顆「篩選 · 排序」(`.ctlfold-b`,沒框文字鈕、高 44、開合列那個三角),有改過的條件數寫在後面(`--accent-ink` 粗字);打開是直式清單(`.ctl-main.open`,一項高 44),不橫捲。
- **開合列**(`details.fold`):公司列、頂部面板、答案庫、卡片「詳細」都是它;左邊一個 `--ink-dim` 三角,打開轉朝下。
- **面板**(`#topbars`、`.prepbar`、`.funnel`、`.cfg-d`、`.cuts`、`.ap-line`):一塊相關的設定或狀態;不包框,用上下一條 `--line` 分段,開合列高 40、滑過 `--surface-2`;`#topbars` 裡「要你處理」自己一列,填表進度、回報、找新職缺、履歷挑法收著時排在同一列(間隔 `--space-24`,手機放不下就折行,找新職缺排在填表進度旁),打開的那個換到這一列後面、撐滿整列,內容接在下面;桌機下緣留 `--space-32`(捲到第一張卡時這一列要整條躲進黏著的分頁列,不露半截);設定頁每項是一列(`.cfg-d`,下緣一條 `--line`),組名 `--text-lg`;`.ap-line` 仍是 `--surface` 底 `--line` 框的小面板。
- **待辦提示**(`.todo`、`.stbar.bad`):這一頁要你處理的;不鋪底不加框,左邊一條 `--warn` 直線(`--shadow-mark-warn`),標題半粗,張數 `--warn` 字。標題的張數連待確認的常用答案一起算;每一列附那張卡的解法(移除、讓 agent 重填,`.todo-b` 小一號的次要按鈕);要他本人登入的那一列多一行開合(`.todo-how`),標題講白要在跑看板的那台電腦上處理,打開是編號步驟(`.todo-steps`);手機上那一列的接手按鈕(重開那一頁、看頁面)字裡就寫「要到跑看板的那台電腦上處理」(`.on-mac`,只在手機出現)。

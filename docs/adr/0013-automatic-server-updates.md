# 開機服務每小時自動更新

## 決策

開機服務啟動的正式看板伺服器每小時檢查遠端 `main`,不依賴頁面開著。自動更新預設開啟,使用者可以在設定頁關閉。只有遠端有新版、程式資料夾在乾淨的 `main`,而且沒有 jobrun 工作或背景重建時才套用;副本與非開機服務不自動檢查或更新。非開機服務仍可由設定頁手動檢查與更新。

更新與開工互斥。更新進行時拒絕新工作、延後背景重建;忙碌時略過自動更新,由下一個小時的檢查再試。程式快轉和依賴安裝視為同一次更新:依賴安裝成功後才回報成功並重啟開機服務;任一步失敗就還原原本的程式版本,嘗試同步原版依賴,不以更新成功的狀態重啟。

設定頁顯示自動更新開關、上次自動更新結果與版本,並保留手動檢查與更新。伺服器版本改變時,沒有未存修改的頁面自動重載;正在編輯或有未存設定時先等到修改存好或放棄後再重載。

## 後果

- 維護者合進 `main` 的改動會在下一次可更新的每小時檢查套用;持續忙碌時會延後。
- 非乾淨的 `main` 不自動改動,設定頁會顯示不能更新的原因。
- 更新失敗時保留舊版本並在設定頁留下結果;舊版依賴同步失敗也會列在結果中。
- 看板頁可以在更新重啟後辨識伺服器版本,避免使用者手動重新整理時丟失尚未儲存的修改。

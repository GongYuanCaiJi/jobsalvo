# 面試題庫(🎤 面試準備那一頁)

看板的「🎤 面試準備」是投遞流程的最後一站:已投遞、而且你在卡上記成「🗣 面試中」或「🎉 Offer」的公司會列在最上面,
下面是你的題庫,照每題走到哪一站分成流水線:還沒答 → 答過第一輪 → 磨合中 → 定案。

題目平常直接在那一頁新增、編輯(「＋ 新增題目」、每題的「✏️ 編輯」)。
已經有一大份題庫想匯入的話,用任何方式產生下面這份 JSON,寫進看板資料的 `bank` 鍵
(用 `tools/board_doc.py` 的 `set_data`,它會拿鎖、不蓋掉別的改動):

```python
import sys; sys.path.insert(0, '<jobsalvo>/tools')
import board_doc as bd
bd.set_data(lambda data, fb: data.__setitem__('bank', my_bank))
```

管線重建看板時會保留 `bank`(`board_doc.EXTRA`),不用每次重裝。

## 格式

```json
{
  "cps": 4.2,                     // 你的語速(字/秒),用來估逐字稿要念幾秒
  "wps": 2.5,                     // 可省略:英文等用空白分字的語言,每秒念幾個字(預設 2.5)
  "cats": ["自我介紹", "你這個人", "你做過的事", "反問面試官"],   // 大類的順序
  "items": [
    {
      "id": "q1",                 // 唯一就好,畫面上不顯示
      "t": "請簡單自我介紹",       // 題名
      "cat": "自我介紹",           // 大類(要在 cats 裡)
      "sub": "",                  // 小類,可空
      "ask": "<p>題面(HTML)</p>",
      "focus": "",                // 考點(HTML),可空
      "covers": "",               // 題組涵蓋哪些子題,可空
      "lim": 0,                   // 限時秒數,0 = 不限;念起來超過會標紅
      "st": "wip",                // "ok" = 定案、"wip" = 磨合中、"todo" = 還沒答案
      "raw": false,               // 有沒有第一輪的原話(st 不是 ok/wip 時,用它分「還沒答」和「第一輪」)
      "asked": ["某公司"],         // 實際被哪家考過,可空
      "b": [                      // 答案:依序的小標與逐字稿
        ["h", "小標(HTML)"],
        ["s", ["第一段逐字稿", "第二段"]]
      ],
      "picks": [["子題名稱", [1, 2]]]   // 子題按鈕:點了只顯示這幾段(段落跨小標連續編號,從 1 開始)
    }
  ]
}
```

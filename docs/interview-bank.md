# 面試準備(🎤 面試準備那一頁)

看板的「🎤 面試準備」是投遞流程的最後一站:已投遞、而且你在卡上記成「🗣 面試中」或「🎉 Offer」的公司會列在最上面,
照下一場面試的時間排。點進一場,上面是什麼時候面、在面什麼,下面是這場的題目,照出處分區:

1. **我被問過**:你在這場實際被問到的
2. **這家考過**:查到別人面這家被問過,附出處
3. **別家考過**:查到別人面別家同類職缺被問過,附出處
4. **預想的**:沒查到出處,從職缺內容推的或常見題

「📚 題庫」那一籤列全部題目,照每題走到哪一站分:還沒答 → 答過第一輪 → 磨合中 → 定案。

人在網頁上改:一題只有一顆「編輯」,在某一場裡按就連這場的出處一起改;題目底下有「＋ 加一題追問」;面試時間有自己的按鈕。agent 一律用 `tools/iv.py`,不要自己組資料寫進看板。

## 面試備忘 PDF

每一場面試的 🎤 面試準備區有「📄 預覽、匯出面試備忘」:先在看板裡預覽排好的 PDF,滿意再按「⬇ 下載 PDF」。手機的瀏覽器不能把 PDF 嵌在框裡看,那裡改成「↗ 開啟 PDF」,用手機自己的檢視器開。命令列:`python3 tools/iv_sheet.py 萬蕙昇`(加 `--md` 只看 Markdown)。PDF 放在資料夾的 `面試備忘/`。

第一頁是速查表,不加標題(每題一行:題目、一句話、要點;不印場次資訊和標題),要問面試官的問題另成一塊,完整回答放附錄。要點寫在逐字稿分界線之前、以「【要點】」開頭的一段,用 ①②③ 寫幾個短句,每句要能單獨看懂,速查表上一句一行;沒寫要點的題,速查改放一句話。附錄每題一塊:題目大字、一句話放在黃色框、完整回答、「對方在看」(考點)、追問縮在原題底下。逐字稿裡單獨一行的 `──────` 是一句話和完整回答的分界;沒有分界的題,整份逐字稿就是回答。內部 id 不印。

## agent 怎麼寫

在資料夾(有 `jobsalvo.json` 的那一層)裡跑:

```bash
python3 tools/iv.py show                    # 每一場什麼時候面、幾題、出處分佈
python3 tools/iv.py show 萬蕙昇              # 一場的面試時間和每一題
python3 tools/iv.py find 薪水                # 先找題庫裡有沒有,有就 link,不要再寫一題一樣的
python3 tools/iv.py get 薪水 > q.json        # 題目參數寫 id 或題目文字的一段都行,對到唯一一題才動;改一題:先拿現在的 json(含 rev),改完再 put
python3 tools/iv.py put q.json --card 萬蕙昇 --src guess --why "職缺寫了模型微調"
python3 tools/iv.py link 萬蕙昇 "怎麼評估一個模型" --src this --cite "面試趣 2026-06-21 https://interview.tw/i/…" --quote "怎麼評估一個模型的好壞"
python3 tools/iv.py unlink 萬蕙昇 "怎麼評估一個模型"
python3 tools/iv.py round 萬蕙昇 --at 2026-10-23T15:00 --how 現場 --where "台北市…" --note "聯絡人…"
python3 tools/iv.py round 萬蕙昇 --del 2026-10-23T15:00
python3 tools/iv.py check                   # 整份不合規則的地方
```

改一題一定先 `get` 再 `put`,不要自己從頭組一整題。每一題帶 `rev`,每存一次加一;`put` 帶的 `rev` 跟現在的不一樣,代表你讀出來之後有人改過這題(看板、別的 agent),這次會被擋下、不會蓋掉別人的改動。被擋就重新 `get`,把你的改動加在最新的版本上再存。

卡片寫網址、網址的一段或公司名都可以,對到唯一一張就好。不合規則的寫入會被擋下並說要改哪裡,規則只寫在
`tools/interview_bank.py` 的 `apply()`,網頁和 `iv.py` 都走它。

## 三層,各放各的

| 放什麼 | 放在哪 | 不放什麼 |
|---|---|---|
| 題目本身:題面、考點、準備材料、逐字稿、走到哪一站 | `bank.items` | 哪一家、出處、日期 |
| 這場用哪一題、出處、為什麼要準備 | `bank.links[卡片 id][題目 id]` | 題目內容 |
| 這場什麼時候面、怎麼面、在哪 | `bank.rounds[卡片 id]` | 投遞日、記成面試中的日子(在卡片上,這頁不用) |

同一題在 A 場是「我被問過」、在 B 場可能只是「預想的」,所以出處記在關聯上,不記在題目上。

### 題目的每一欄

- `t` 題目:一句話,畫面上那一行。
- `ask` 題面:**只寫對方怎麼問**。查到的考題照原文抄。出處、日期、「答壞的樣子」放這裡會被擋。
- `focus` 考點:對方在看什麼、答壞的樣子。
- `ref` 準備材料:答之前要先讀懂的東西(筆記、影片第幾分、原始資料)。
- `script`(存成 `b`)逐字稿:空一行是下一段;`## ` 開頭的一行是小標,只用在同一個答案的段落或版本(60/90 秒版、A/B 版、對方開的比預期低)。
- `stage` 走到哪:`todo` 還沒答 / `first` 答過第一輪 / `wip` 磨合中 / `ok` 定案。沒有逐字稿不能是磨合中或定案。
  只算這一題自己的答案:原題定案了,它的追問可能還在磨。原題那一行(看板、`iv.py show`、`iv.py find`)會寫「追問 N 題,M 題還沒定案」,
  要知道一整串能不能上場看那一句,不要只看原題的 `ok`。
- 題面、考點、準備材料、逐字稿裡的連結寫 `[文字](網址)`,看板顯示時才變成可點的連結(編輯存檔不會掉)。
- `cat` 大類(照 `bank.cats` 排)、`sub` 小類、`lim` 限時秒數(0 = 不限,念起來超過會標紅)。
- `parent` 追問:這題是哪一題的追問。**追問 = 對方聽完這題的回答,接著問的另一個問題**,一律寫成另一題、`parent` 指到原題,
  不准寫進原題的逐字稿(小標寫「追問」會被擋)。從職缺或回答推出來的追問,出處是 `guess`,`why` 寫從哪裡推的。只有一層:追問底下不能再掛追問,底下有追問的題也不能當別題的追問。在同一場裡,追問收在原題裡面,不另佔一行;題庫裡各自一行,點開標「追問自哪一題」。
- `picks` 子題按鈕:`[["子題名稱", [段落編號…]]]`,點了只顯示那幾段(段落跨小標連續編號,從 1 開始)。

- 題面、考點、準備材料、逐字稿都是寫給你讀的:講你用「你」,不要寫「他的材料」。某一場才有的理由寫在那一場的 `why`,不寫進題目。

### 出處(`links` 的一筆)

```json
{"k": "prep", "src": "this", "cite": "面試趣 2026-06-21 https://interview.tw/i/6a37e69e59ac3155e40ef2d5", "quote": "怎麼評估一個模型的好壞", "why": ""}
```

- `src`:`me` 我被問過 / `this` 這家考過 / `other` 別家考過 / `guess` 預想的。
- `k`:`asked`(被問過)只跟 `me` 一起;其他都是 `prep`(要準備)。
- `cite`:`this`、`other` 必填,寫哪個網站哪一天,加**那一篇**的網址(面試趣 `interview.tw/i/…`、GoodJob `goodjob.life/experiences/…`),不是公司頁。看板上網址變成「看原文↗」,點了直接開那一篇。一筆出處來自兩篇就兩個網址都附。只有自己被問過、沒有網頁的例外,`cite` 用「我 2026-08-28 在…被問過」開頭。查不到就是 `guess`,不准填一個看起來像出處的東西。
- `quote`:`this`、`other` 必填,那一篇的原文,怎麼寫就貼怎麼寫,不改寫。付費牆後面看不到的,貼看得到的那段,截斷的地方照原樣留「...」。題目 `t` 是我們整理過的問法,`quote` 是人家的原話,兩個都要。
- `why`:為什麼這場要準備。`iv.py` 寫 `guess` 時必填(從職缺哪一句推的)。

### 面試時間(`rounds` 的一筆)

```json
{"at": "2026-10-23T15:00", "how": "現場", "where": "台北市信義路三段132號8樓", "note": "聯絡人 廖小姐"}
```

`at` 寫 `2026-10-23` 或 `2026-10-23T15:00`;`how` 是 現場/電話/視訊/AI 錄影/筆試/其他。

## 共有題與這場版

每一場都會問的題(自我介紹、期望待遇、可上班日)不用一場一場勾,也不用複製:題目設成**共有**(`item.shared`),每一場面試自動帶上,追問跟著原題。改共有版,所有面試一起更新。

某一場想講得不一樣,對那一題按「只改這場」:存成**這場版**(`links[面試][題].ov = {b, focus}`),只有那一場看到、印出來是這個版本,共有版和其他面試不動。「還原成共有版」就刪掉這場版。

- 看板:面試頁頂端是「🤝 共有」區;「🤝 共有」分頁看與管理全部共有題;題目展開有「改共有版」「只改這場」「共有中 · 取消」。
- agent:`iv.py share <題>` / `unshare <題>`;`iv.py variant <面試> <題> --script-file F [--focus-file F]`,`--clear` 還原。
- 查一場看到哪些題:`interview_bank.job_qids`;那一場實際的內容:`interview_bank.effective`。
